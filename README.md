# AI UI QA Assistant

An AI-powered UI testing assistant built using Python.

## Features

- Generate functional test cases
- Generate negative scenarios
- Identify edge cases
- Generate UI/UX scenarios
- Identify accessibility scenarios
- Identify security scenarios
- Analyze real-world user journeys
- Generate Playwright automation candidates

## Technology

- Python
- Streamlit
- OpenAI API
- Playwright
- JSON

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
